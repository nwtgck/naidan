### Fixed

- Resolve symbolic links before processing `..` when opening, removing, or moving files in the shell, so operations reach the intended file. Reject missing path components before `..`.
- Create directories in path order with `mkdir -p` and place new symbolic links and FIFOs in the resolved directory. Compute relative links from the directory where the link will be created.
- Resolve script paths in filesystem order for command execution, `command -v`, and `type`. Paths with missing parent components no longer invoke a registered command by mistake.
