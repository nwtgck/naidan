### Fixed

- Let shell scripts handle trapped signals and continue. A trapped signal can interrupt `wait` while keeping the child available to wait on again. Signals sent only to a child no longer run the parent shell’s trap.
- Keep running commands active when they receive signals such as `WINCH` or `URG` with their default dispositions.
- Run the shell’s `EXIT` trap on an unhandled `SIGTERM` while separately running children keep their file descriptors. `SIGKILL` can end a trap that is blocked writing to a pipe.
- When a script receives `SIGINT` while waiting for a foreground command, use the child’s actual termination reason. A normal exit with status 130 can still pass control to the next command.
